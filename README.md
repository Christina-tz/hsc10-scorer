# 第十届幻术杯 · 计分器 & 参赛名单

《第十届幻术杯》（沉沦者的黑流树海 · N16）现场计分用单页工具，纯前端、无依赖、手机可用。

- **计分器** → [index.html](https://christina-tz.github.io/hsc10-scorer/)（根路径直接打开）
- **参赛名单** → [roster.html](https://christina-tz.github.io/hsc10-scorer/roster.html)

## 计分器

总分口径与官方《幻术杯 #10 加分表》一致：

```
总分 =（ 结算分 − 零件数×1.5 + 紧急与特殊作战 + 结局/BOSS + 其他加分 ）× 抗压位系数 + 扣分
```

- **抗压位【引路人】×1.3**，无蓝图 −500（在 ×1.3 之后结算）
- **取款额度 200**，超出每点 −50（第一层商店那一次不计入）
- **时长 ≥4 小时**起扣，每满 30 分钟 −200，上不封顶
- **紧急作战逐场记录**：点 ＋ 勾选「探险家存活 / 持蓝图 / 漏怪」，按规则自动算分
  - 探险家存活 ×1.5（无基础分则 +15）→ 漏怪：无蓝图 ×0.5、持蓝图不扣半 → 无漏且持蓝图 ×1.5
  - 每场记录会在关卡名下列成小表格，可单条删除
- **队伍 / 选手联动选择**：8 支队伍、28 名选手内置；先选队伍则选手列表只显示该队，直接选选手会自动带出队名；也支持手动输入名单外的人
- 支持「保存到队伍」，自动按分数排序、统计指引者/引路人人数、算队伍总分
- **「填官方加分表」**：把计分器结果换算成官方表要填的「次数」，分 4 段一键复制，粘到 `D17` / `D30` / `I16` / `I30` 即可逐行填入；结算分、零件、抗压系数、扣分单列
- **零件扣除系数可切换**（×7.5 / ×1.5）：官方模板公式是 ×1.5，主办方实际在用的汇总表按 ×7.5 扣，默认 ×7.5
- **BOSS 勾选支持 0.5**：BOSS 进入目标点，该关卡分数减半
- **队伍加分**独立结算，**不计入个人总分**：「同队同时击杀 1、2、4 结局 BOSS +300」+ 其他手动加减，只叠加到队伍总分
- 数据只存在本机浏览器（localStorage），刷新不丢，不上传任何服务器

## 参赛名单

按队伍归类 28 名选手，标注比赛时间与星期，并标出**解说席已满**的场次；不含替补。
